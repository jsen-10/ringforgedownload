# Downloads

Put the release zip here as **`RingForgeStudio.zip`**.

When this file exists, the site's download buttons serve it directly.
If it's missing, they fall back to the Smash link:
https://fromsmash.com/ringforgestudiodownload

GitHub blocks files over 100 MB. For a bigger zip, attach it to a
GitHub Release instead, or keep using Smash.
